## 2. Магазинный автомат для языка L12

**Файл JFLAP:** [L12_PDA.jff](L12_PDA.jff).

### 2.1. Условие и принцип работы

Входная цепочка должна иметь вид **aⁿbᵐ**: буквы a, если они есть, идут перед буквами b. Количество a и b должно быть **разным**.

Например, **aab** и **abb** подходят, а **aabb**, **ab** и **ba** — нет.

Для сравнения количеств используется магазин (стек):

- В начале стек содержит **Z**.
- За каждую прочитанную **a** в стек добавляется **A**.
- За каждую прочитанную **b** одна **A** снимается со стека.
- Если вход полностью прочитан и A осталась, то **n > m**: принятие через **q3**.
- Если A закончились и встретилась лишняя b, то **n < m**: принятие через **q4**.
- Если количество a и b одинаковое, автомат не имеет принимающего пути.

Формальное описание:

**M = (Q, Σ, Γ, δ, q0, Z, F)**, где:

| Элемент | Значение |
|---|---|
| Q = {q0, q1, q2, q3, q4} | Состояния автомата |
| Σ = {a, b} | Входной алфавит |
| Γ = {A, Z} | Алфавит магазина (стека) |
| δ | Функция переходов |
| q0 | Начальное состояние; обработка букв a |
| Z | Начальный символ магазина |
| F = {q3, q4} | Принимающие состояния |

Назначение состояний:

| Состояние | Назначение |
|---|---|
| q0 | Добавление A в стек при чтении a |
| q1 | Чтение b и удаление A из стека |
| q2 | Чтение дополнительных b после исчерпания A |
| q3 | Финальное состояние для n > m |
| q4 | Финальное состояние для n < m |

**Критерий принятия:** достижение финального состояния **после полного прочтения входной цепочки**. Попадание в q3 или q4, пока на входе ещё есть символы, само по себе не означает принятия.

### 2.2. Переходы автомата

В таблице **ε** означает пустую строку: ε в поле «Читаем» — переход без чтения символа, а ε в поле «Кладём» — удаление вершины стека без замены. В окнах JFLAP тот же пустой символ может отображаться как **λ**.

| Переход | Читаем | Снимаем со стека | Кладём в стек | Объяснение |
|---|---|---|---|---|
| q0 → q0 | a | Z | AZ | Первая a: добавляем A поверх Z |
| q0 → q0 | a | A | AA | Очередная a: добавляем A |
| q0 → q1 | ε | Z | Z | Переходим к этапу b при пустом счётчике A |
| q0 → q1 | ε | A | A | Переходим к этапу b, не меняя A |
| q1 → q1 | b | A | ε | При чтении b удаляем одну A |
| q1 → q3 | ε | A | A | Переход к финальному состоянию при оставшейся A |
| q1 → q2 | b | Z | Z | Прочитали лишнюю b после исчерпания A |
| q2 → q2 | b | Z | Z | Продолжаем читать лишние b |
| q2 → q4 | ε | Z | Z | Переход к финальному состоянию при избытке b |

Автомат **недетерминированный**: при обработке одного слова JFLAP может одновременно показать несколько возможных веток. Красная конфигурация означает, что данная ветка не привела к принятию; при этом другая ветка может успешно принять слово. Для принятия достаточно одного успешного пути.

## 3. Контекстно-свободная грамматика для языка L28

**Файл JFLAP:** [L28_CFG.jff](L28_CFG.jff).

### 3.1. Условие и правила

Задан язык **L28 = { aⁿbᵐcᵏ | n, m, k ≥ 0, k = n + m }**.

Сначала должны идти буквы a, потом b, затем c. Число c должно быть равно общему числу a и b.

Грамматика записывается как **G = (V, Σ, P, S)**:

| Элемент | Значение |
|---|---|
| V = {S, T} | Нетерминалы — служебные символы, заменяемые по правилам |
| Σ = {a, b, c} | Терминалы — символы готовой цепочки |
| P | Правила вывода |
| S | Начальный символ |

**Правила P:**

| Правило | Значение |
|---|---|
| S → aSc | Добавляем одну a слева и одну c справа |
| S → T | Заканчиваем создавать a и переходим к этапу b |
| T → bTc | Добавляем одну b слева и одну c справа |
| T → ε | Завершаем вывод; нетерминал T исчезает |

Каждое добавление a или b сопровождается добавлением одной c. Так сохраняется условие **k = n + m**.

## 4. Доказательство неконтекстно-свободности языка L44

Для языка **L44 = { w ∈ {a, b, c}* | nₐ(w) = nᵦ(w) = n꜀(w) }** требуется равное количество трёх букв, но порядок их расположения **произвольный**.

Покажем по **лемме о разрастании контекстно-свободных языков**, что L44 не является контекстно-свободным.

1. **Предположение от противного.** Пусть L44 является контекстно-свободным. Тогда для него существует длина накачки **p ≥ 1**.
2. **Выбор слова.** Возьмём **s = aᵖbᵖcᵖ**. Оно принадлежит L44, поскольку число букв каждого вида равно p. Длина слова равна 3p, то есть не меньше p.
3. **Условия леммы.** Для достаточно длинного слова существует разбиение **s = uvxyz**, в котором **|vxy| ≤ p**, **|vy| > 0**, а все слова **uvⁱxyⁱz** должны принадлежать L44 для любого целого **i ≥ 0**.
4. **Ограничение разбиения.** Так как участок vxy имеет длину не более p, он не может одновременно содержать буквы из первого блока a и третьего блока c: между ними находится блок из p букв b. Поэтому части v и y могут затрагивать буквы **не более двух** из трёх типов.
5. **Накачка.** Выберем **i = 2**. Мы добавим ещё по одной копии частей v и y. По условию **|vy| > 0** число букв хотя бы одного типа возрастёт; число букв хотя бы одного другого типа останется прежним.
6. **Противоречие.** В слове **uv²xy²z** количество a, b и c уже не может быть одинаковым. Следовательно, это слово не принадлежит L44, что противоречит лемме.

**Вывод:** язык L44 **не является контекстно-свободным**.

Это формальное доказательство. Скриншоты игры **Context-Free Pumping Lemma** для L44 в папке screenshots не представлены. Встроенная в JFLAP игра с готовым языком **{aⁿbⁿcⁿ | n ≥ 0}** относится к другому языку и сама по себе не является прямой демонстрацией L44.

- **README.md** — описание задания, переходов, результатов тестирования и доказательства.

Для демонстрации преподавателю: откройте **L12_PDA.jff** в JFLAP и выполните **Input → Step by State** для aab, abb и aabb; затем откройте **L28_CFG.jff** и покажите вывод aabbcccc в **Input → User Control Parse** и проверки abcc / abc через **Brute Force Parse**. Третья часть в текущем репозитории представлена формальным доказательством в разделе 4.
