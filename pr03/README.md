## 2. МПА для L12

Файл: [L12_PDA.jff](L12_PDA.jff). **Критерий принятия — по финальному состоянию, после полного чтения входа.** Начальный символ магазина — `Z`. Финальные состояния: `q3`, `q4`.

Формально M = (Q, Σ, Γ, δ, q0, Z, F), где Q = {q0,q1,q2,q3,q4}, Σ = {a,b}, Γ = {A,Z}, F = {q3,q4}.

**Идея:** q0 считает символы `a`, кладя по одному `A` в магазин; q1 снимает `A` за каждый `b`. Если остались `A`, значит n > m и доступно q3. Если `A` закончились, дополнительный `b` переводит в q2, после чего допускаются только `b`; затем доступно q4. Таким образом, равенство n = m не принимается. Пустая строка также не принимается.

Таблица переходов (запись `вход, снять; положить`; ε — пустая строка):

| Из | В | Метка |
|---|---|---|
| q0 | q0 | a, Z; AZ |
| q0 | q0 | a, A; AA |
| q0 | q1 | ε, Z; Z |
| q0 | q1 | ε, A; A |
| q1 | q1 | b, A; ε |
| q1 | q3 | ε, A; A |
| q1 | q2 | b, Z; Z |
| q2 | q2 | b, Z; Z |
| q2 | q4 | ε, Z; Z |

**Замечание:** переход в финальное состояние может существовать до конца ввода, но принятие требует, чтобы вход был прочитан полностью.

### Пошаговые вычисления МПА

Конфигурация записывается как (состояние, непрочитанный вход, магазин); верх магазина — слева.

**`aab` — Accept, n=2 > m=1:**

```text
(q0, aab, Z)
→ (q0, ab, AZ)
→ (q0, b, AAZ)
→ (q1, b, AAZ)
→ (q1, ε, AZ)
→ (q3, ε, AZ)  ACCEPT
```

**`abb` — Accept, n=1 < m=2:**

```text
(q0, abb, Z)
→ (q0, bb, AZ)
→ (q1, bb, AZ)
→ (q1, b, Z)
→ (q2, ε, Z)
→ (q4, ε, Z)  ACCEPT
```

**`aabb` — Reject, n=m=2:**

```text
(q0, aabb, Z)
→ (q0, abb, AZ)
→ (q0, bb, AAZ)
→ (q1, bb, AAZ)
→ (q1, b, AZ)
→ (q1, ε, Z)  REJECT
```

Другие проверки: `ε` Reject; `a` Accept; `b` Accept; `ab` Reject; `aaab` Accept; `abbb` Accept; `ba` Reject; `aabbcc` Reject.

## 3. Контекстно-свободная грамматика L28

Файл: [L28_CFG.jff](L28_CFG.jff). Существующая грамматика сохранена без изменений:

```text
S → aSc | T
T → bTc | ε
```

Здесь S — стартовый символ, терминалы a,b,c. Правило S → aSc добавляет одну a и одну c; T → bTc добавляет одну b и одну c. Следовательно, получаем ровно aⁿbᵐcⁿ⁺ᵐ для любых n,m ≥ 0.

**Пример вывода `aabbcccc`:**

```text
S ⇒ aSc ⇒ aaScc ⇒ aaTcc ⇒ aabTccc ⇒ aabbTcccc ⇒ aabbcccc
```

| Цепочка | Ожидаемый результат |
|---|---|
| ε | Accept |
| ac | Accept |
| bc | Accept |
| abcc | Accept |
| aabbcccc | Accept |
| abc | Reject |
| aabbc | Reject |
| aabbbcc | Reject |
| ba | Reject |

Для JFLAP использовать `Input → Brute Force Parse` или `Input → User Control Parse`. Реальные скриншоты результатов и промежуточных шагов необходимо добавить по инструкции.

## 4. Формальное доказательство: L44 не является КСЯ

**Утверждение:** L44 = {w ∈ {a,b,c}* | nₐ(w) = nᵦ(w) = n꜀(w)} не является контекстно-свободным языком.

**Доказательство от противного (лемма о разрастании для КСЯ).**

Предположим, что L44 — контекстно-свободный язык. Тогда существует длина накачки p ≥ 1 такая, что всякое слово s ∈ L44 с |s| ≥ p допускает разбиение s = uvxyz, где |vxy| ≤ p, |vy| > 0, и для всех i ≥ 0 слово uvⁱxyⁱz принадлежит L44.

Выберем s = aᵖbᵖcᵖ ∈ L44. Так как |vxy| ≤ p, подслово vxy не может одновременно затрагивать блок a и блок c: между ними целый блок из p символов b. Следовательно, v и y вместе содержат символы не более двух из трёх типов a,b,c.

Поскольку |vy| > 0, при i=2 количество хотя бы одного из этих типов возрастёт. При этом количество хотя бы одного другого типа не изменится. Поэтому в слове uv²xy²z количества a,b,c уже не будут равны. Значит, uv²xy²z ∉ L44 — противоречие лемме.

**Вывод:** L44 не является контекстно-свободным языком.
