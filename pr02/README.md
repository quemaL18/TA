**Часть 1-2. Язык L13.** Алфавит Σ = {0, 1}. Язык:

    L13 = { w ∈ {0,1}* | w заканчивается на 010 }

Идея построения: строка должна заканчиваться фиксированным суффиксом 010, перед которым может стоять любая последовательность символов 0 и 1.

**Регулярное выражение:**

    (0+1)*010

**Формальное описание ДКА:**

- Q = {q0, q1, q2, q3} - 4 состояния;
- Σ = {0, 1};
- q0 = q0 - начальное;
- F = {q3} - допускающее;
- δ задана таблицей:

| Состояние | 0 | 1 |
|-----------|---|---|
| -> q0 | q1 | q0 |
| q1 | q1 | q2 |
| q2 | q3 | q0 |
| q3 (final) | q1 | q0 |

**Регулярная грамматика:**

    S -> 0S | 1S | 0A
    A -> 1B
    B -> 0C
    C -> eps

**Часть 3. Язык L39.** Алфавит Σ = {0, 1, 2}. Язык:

    L39 = { 0^n 1^m 2^n | n, m >= 0 }

Требуется доказать, что L39 не является регулярным.

### 4.5 Доказательство нерегулярности L39

**Утверждение:** L39 = { 0^n 1^m 2^n | n, m >= 0 } не является регулярным языком.

**Доказательство (лемма о разрастании):**

1. Предположим, что L39 регулярен. Тогда существует p (длина накачки).
2. Возьмём s = 0^p 1^p 2^p. Заметим: s принадлежит L39, так как n = p, m = p, n0 = n2 = p. При этом |s| = 3p >= p.
3. По лемме о разрастании s = xyz, где |xy| <= p, |y| >= 1.
4. Так как |xy| <= p, а первые p символов строки s - это нули, то xy состоит только из нулей. Значит, y = 0^k, где k >= 1.
5. Рассмотрим строку xy^2z (накачка i = 2):

       xy^2z = 0^(p+k) 1^p 2^p

6. В этой строке количество нулей равно p + k, а количество двоек равно p. Так как k >= 1, получаем p + k != p. Условие 0^n 1^m 2^n нарушено. Следовательно, xy^2z не принадлежит L39.
7. Противоречие с леммой о разрастании. Значит, предположение неверно.
8. **Вывод:** L39 не является регулярным языком.

---

### 4.6 Дополнительно: L30 = {a^n b^l : n <= l}

**Утверждение:** L30 не является регулярным языком.

**Доказательство (лемма о разрастании):**

1. Предположим, L30 регулярен. Тогда существует p.
2. Возьмём s = a^p b^p. Заметим: s принадлежит L30, так как n = p, l = p, n <= l. При этом |s| = 2p >= p.
3. По лемме s = xyz, где |xy| <= p, |y| >= 1.
4. Так как |xy| <= p, а первые p символов - это a, то y = a^k, k >= 1.
5. Возьмём i = 2: xy^2z = a^(p+k) b^p.
6. Теперь n = p + k, l = p. Условие n <= l нарушено: p + k > p при k >= 1. Значит, xy^2z не принадлежит L30.
7. Противоречие. **L30 не регулярен.**
